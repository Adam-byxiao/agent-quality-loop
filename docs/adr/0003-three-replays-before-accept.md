# ADR-0003：三次独立回放，3/3 通过才接受

## 背景

回放一次候选提示词，通过了。能接受吗？

## 备选

1. 一次通过即接受；
2. 两次全部通过；
3. 三次全部通过；
4. 三次中两次通过（多数票）。

## 决定

选 3：同一冻结主键、同一候选，独立回放三次，**全部通过**才接受。逐次结果原样记录，不是只记"验证通过"。

## 代价

- 验证成本 ×3；
- 收敛更慢，某些"其实可用"的候选会被拒；
- 不代表统计意义上的稳定性（三次仍然是小样本），报告的局限声明必须写明。

## 为什么

- 单次通过无法区分"真的修好"与"这次碰巧"；
- 多数票会把不稳定候选放进来，而且隐藏了不稳定这个事实；
- 逐次记录让失败可复盘：是模型输出抖动，还是候选本身不完整。

## 证据

demo 第 2 次提案：`1/3 ✓ · 2/3 ✓ · 3/3 ✗` → 拒绝，资产序号不变。第 3 次 `3/3 ✓` 才接受。
